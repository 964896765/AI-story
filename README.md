# AI 漫剧工厂

面向 Windows 的本机生产工作台。已有原始素材管理、真实视频剪辑导出、持久化任务与恢复、创作版本及固定生产引用。P5 提供文本模型预算、人工对账和离线改编审核。P6 提供本地多媒体解析、证据审核和创作采纳。真实模型调用默认关闭，真实预算为 0。 [阶段验收](docs/ACCEPTANCE.md) · [能力矩阵](docs/CAPABILITY_MATRIX.md)

## 本地启动

现有工具要求：Python 3.10+、Node 20.19+、Docker Desktop Linux Engine、FFmpeg/ffprobe（PATH 可调用）。服务仅绑定 127.0.0.1，不部署公网。

1. 在根目录复制 `.env.example` 为 `.env`，设置强随机 PostgreSQL 密码，同时更新 `DATABASE_URL` 中的密码（URL 保留字符须百分号编码）。不要提交 `.env`。
2. 启动 Docker Desktop，确认 `docker info` 成功。
3. 根目录执行 `docker compose up -d db`。首次运行会下载 PostgreSQL 16 镜像，不会下载 AI 模型。
4. 根目录执行 `python -m venv .venv`，然后 `.\.venv\Scripts\python -m pip install -r backend/requirements.lock`。
5. 在 `backend` 目录执行 `..\.venv\Scripts\alembic upgrade head`。
6. 在 `backend` 目录分别开两个终端运行：
   - `..\.venv\Scripts\python -m uvicorn app.main:app --host 127.0.0.1 --port 18000`
   - `..\.venv\Scripts\python -m app.worker`
7. 在 `frontend` 目录执行 `npm ci` 和 `npm run dev`，打开 http://127.0.0.1:15173 。

进入素材资产中心，新建项目，填写授权来源，批量导入视频、音频、UTF-8 SRT/TXT 或授权参考图片。原有“读取媒体信息”保留。在“智能二创”多选视频、设置剪辑参数并提交；“批量生产”查看真实阶段、编码进度、耗时、参数和日志，或取消/重试；“质检与导出”预览和下载已验证成片。播放受浏览器编码支持限制。

## P2 剪辑规则

- 开始时间默认 0；结束时间与时长二选一，留空表示到视频末尾。超出素材范围拒绝处理，不悄悄截短。
- 画幅可保留原始比例，或转为 9:16、16:9、1:1。crop 居中裁切填满，pad 等比缩放并加黑边，fit 仅等比缩放、实际输出尺寸随内容变化。
- 分辨率支持源尺寸基准或短边 720/1080/1440/2160；原画幅+源尺寸为默认，不强制降分辨率或帧率。H.264 CRF 默认 18，AAC 192k，均为重新编码，非无损复制；CRF 0 可用于 H.264 无损模式但会增大文件。仅输出 SDR 8-bit yuv420p；HDR/高位深会明确拒绝，避免静默降质。
- 输出 MP4 或 MKV（H.264/AAC），MKV 可能需外部播放器。视频旋转和 SAR 在输出中归一化，尺寸取偶数。输出最大边长 8192、总像素最多 3600 万，单编码器线程限制为 2。
- SRT 最大 2 MiB，UTF-8 或 UTF-8 BOM；时间相对裁剪后片段起点。烧录后不可关闭。没有字幕不报错，指定了缺失/无效字幕则任务失败。字幕字形取决于本机字体；部署前须确认所需中文字体及其授权。
- 保留原音、替换音轨或移除音轨；音量 0–4 倍。原片无音轨时保留无音轨。替换音频从开头播放，短则补静音、长则截断，不自动循环。
- 在当前浏览器标签页、当前项目批次内，按输入与参数复用幂等键，刷新或切换工作区后仍可重用；“开始新批次”才主动重置。新标签页为独立批次；直接 API 调用者应持久保存自己的幂等键。

API 文档：http://127.0.0.1:18000/docs 。健康检查 `/api/health` 在数据库、迁移或工具未就绪时返回 503。前端遇到错误显示实际错误，不注入演示数据。

## 验证

在 backend 目录运行 `..\.venv\Scripts\python -m pytest -q`。包含 FFmpeg 自行生成的一秒测试视频，不使用未授权素材。

PostgreSQL 集成测试需独立测试数据库，先以其 `DATABASE_URL` 执行迁移，再设置 `TEST_DATABASE_URL` 指向同一测试库后运行 pytest。不要对生产库运行集成测试。未配置时测试明确跳过，不代表通过。

也可在根目录设置好 `TEST_DATABASE_URL` 后运行 `.\.venv\Scripts\python scripts/integration.py`，脚本仅对指定测试库迁移并执行测试。

前端：`npm run build` 同时执行 Vue/TypeScript 类型检查。

## 数据、安全与恢复

- PostgreSQL 保存项目、素材、任务、事件与费用；视频保存在 `data/originals`，UUID 命名，不采用上传者提供的磁盘路径。API 无任意路径导入接口。
- 上传单文件最大 2 GiB，流式复制并计算 SHA-256。重复哈希可识别同内容，但目前不自动去重。文件与数据库无法组成原子事务，异常退出可能留下孤立文件；备份和清理前须对照资产表，禁止直接删除原始素材。
- Worker 使用 `FOR UPDATE SKIP LOCKED` 领取任务；每个进程一次处理一个任务。解析超时 60 秒、租约 120 秒；过期解析任务标记失败，可手动重试。P3 心跳独立于处理阶段，每 2 秒写入；批量生产面板显示在线/离线及最近心跳，超过 15 秒未更新视为离线。
- P2 新增 PostgreSQL advisory lock，同一数据库的所有 Worker 最多同时执行 1 项任务。剪辑任务每约 0.5 秒续租（30 秒租约），进度来自 FFmpeg `out_time_us`，100% 仅在输出验证与发布后写入。解析任务仍保留最长 60 秒探测/120 秒租约。
- 排队任务立即取消；运行剪辑在下一次取消检查时终止 FFmpeg（正常约 0.5 秒，强杀兜底 5 秒；阻塞探测阶段最长等待 60 秒）。若取消与已经完成的原子发布竞争，已发布的成功结果优先，不删除成片。Windows Job Object 在 Worker 异常退出后清理编码子进程。
- Worker 重启后需等待旧租约过期；未完成剪辑自动恢复，任务累计尝试达到 3 次时不再自动恢复、标失败供人工重试。P3 会核验前次已编码临时文件的输入/参数签名、SHA-256 与媒体格式，符合才跳过重复编码；否则重新编码，不提供帧级续算。若已发布而数据库未提交，则核对清单和文件哈希后复用已有成片（P2旧清单没有哈希时沿用媒体验证）。失败与取消可手动重试，新尝试使用独立目录，不覆盖其他任务。
- 媒体任务的幂等键在项目内唯一，同键不同素材、任务类型或参数返回冲突；重试保留任务 ID、递增尝试次数并追加日志。P5文本调用有独立的费用治理与受控重试入口，禁止走媒体任务重试。
- 浏览器每 3 秒查询真实任务状态。没有模型费用记录时显示已入账费用为零，明确不含机器、电力等成本。
- 每次剪辑保留 `data/tmp/<任务ID>/<尝试次数>/command.json`、`ffmpeg.log` 和验证清单。成功成片在 `data/outputs/<任务ID>/video.mp4`（或 `.mkv`）。只有 ffprobe 验证通过才以同卷硬链接+删除临时入口方式原子发布，不覆盖既有文件；存储须支持硬链接（当前 Windows NTFS 已验证）。磁盘不足/超时/编码器缺失会记录失败，原始素材不变。保留的中断临时文件和日志目前需人工清理，不自动删除。
- 无用户账号系统，仅限同机可信用户；Host、Origin 和客户端地址检查提供基础本机防护，不用于多用户或公网环境。
- P5文本预算预留、限额拦截、未知结果占用、用量核算及人工凭证对账已实现。真实调用默认关闭，所有启用条件见 [文本治理契约](docs/P5_MODEL_CONTRACT.md)；本阶段未授权任何真实请求。
- 不使用 Docker 卷删除命令。备份需停止写入与 Worker，使用 `pg_dump` 备份数据库并同步复制整个 data 目录，在独立数据库恢复并校验哈希后再切换。自动备份/恢复演练留待后续验收。

## 许可证

依赖初步审核与限制见 [LICENSE_REVIEW.md](docs/LICENSE_REVIEW.md)。本项目未决定源码对外授权协议；这不替代依赖各自许可。FFmpeg 采用外部进程调用且不随项目分发，商用分发前应审查具体构建、通知义务与编码专利。

已配置完成时，也可在根目录运行 `powershell -ExecutionPolicy Bypass -File scripts/start.ps1` 隐藏启动三个进程。日志和 PID 存于 `data/runtime`；如需关闭，先核对记录 PID 的实际命令行再停止对应进程。脚本遇到端口占用会退出，不终止其他服务。P3 记录进程启动时间和可执行文件，过期记录由启动脚本归档；`powershell -NoProfile -ExecutionPolicy Bypass -File scripts/stop.ps1 -WhatIf` 可检查将停止的本项目进程，再去掉 `-WhatIf` 实际停止。身份不匹配就拒绝操作，不按端口或复用 PID 杀进程。停止前建议等待任务结束或取消；强制停止的任务通过租约恢复。

升级时先停止本项目 API 与 Worker，备份数据库与 data，在 backend 执行 `..\.venv\Scripts\alembic upgrade head`（当前 P12 为 0011），再重新启动。前端重新执行 `npm run build` 或使用 Vite 开发服务。 [P12 恢复步骤](docs/P12_ACCEPTANCE.md)

P2 实机验证脚本：服务运行后根目录执行 `.\.venv\Scripts\python scripts/p2_smoke.py`，会创建明确标识的验收项目与自有测试视频，并生成两条真实成片。浏览器验证使用本机 Chrome：`node --experimental-websocket scripts/browser-p2.mjs`，独立临时浏览器配置，不下载浏览器或模型；会再创建一条真实任务。


## P3 批量可靠性

- 智能二创改为 `POST /api/projects/{id}/batches`，一次最多100个不同视频；输入、关联资产、参数检查全部通过后，整批任务才在同一事务提交。响应丢失时，用相同批次键重试，返回原批次；同键不同请求返回409。旧单任务API继续支持。
- “暂停队列”持久化停止领取新任务，已执行任务继续；恢复和单任务取消仍然有效。是当前数据库的全局控制，不是单项目暂停。
- 每次执行在 task_attempts 中保存输入快照、参数、Worker、阶段时间点、耗时、结果和错误码。P2历史不伪造补录；FFmpeg日志接口最多显示末尾64 KiB。
- 超时、暂时资源繁忙、数据库/心跳异常可安排有限延迟重试，默认累计最多3次，退避5/10秒（函数封顶60秒）。无效输入、缺失文件/工具、磁盘不足、编码或输出校验失败需要修复后手动重试，不无限循环。
- 心跳异常/所有权丢失会阻止继续处理和发布；有效运行租约是 advisory lock 之外的第二道领取限制。正常独立心跳续租为30秒，解析任务初始租约仍可达120秒；Worker中断后等待原租约过期再恢复。
- 已观测处理耗时按尝试累加，包括失败；崩溃可能少计。人民币费用与其他币种分开，不自动汇率换算；P3原有成本台账保留，P5文本治理使用独立且区分模拟/真实的预算账本。
- 数据库连接超时3秒、单SQL超时10秒、锁等待3秒；后续大规模迁移需要单独评估该限制。Worker启动时数据库未就绪会等待重试。

P3实机验收：`.\.venv\Scripts\python scripts/p3_smoke.py`。如果已有活动任务或用户已暂停队列，脚本拒绝更改队列；通过时会生成明确标识的测试项目和真实成片。浏览器验收：`$env:QA_PHASE='p3'; node --experimental-websocket scripts/browser-p2.mjs`，使用独立本机Chrome配置。


## P4 创作资产基础

“漫剧定制”提供小说、剧本、角色、场景、人物关系、分集、分镜及模型输入计划。所有保存均追加版本；并发编辑基于期望版本检查，冲突返回409，不覆盖别人已保存的内容。历史版本可比较或追加恢复，不删除中间版本。角色、场景、来源、配音参考均固定到具体版本/素材。

- 文本正文最多100万字符、单版本JSON最多2 MiB。TXT须为UTF-8（可含BOM），原始文件最多2 MiB；PNG/JPEG/WebP参考图最多20 MiB。参考图片只做文件头检查，不等于全面解码/安全检测。原始文件与授权说明保留。
- 角色包含外貌、性格、声音说明、声音标识、授权音频与图片参考；这些是创作配置，不会生成配音或保证模型跨镜头一致性。
- 规则整理为剧本保留原文；分集/分镜按段落和字符数拆分，长段可在字数处切断，必须人工审核剧情与对白。单次最多50集或200镜头。分镜默认3秒仅为可编辑计划，没有生成视频。
- 浏览器草稿保存在当前标签页sessionStorage，不等于数据库保存；缓存失败会提示。关闭标签页后不要依赖草稿恢复，重要内容应保存版本。项目切换按项目隔离草稿。
- 目录与历史API默认只返回元数据，正文按具体版本加载。列表每页最多200项、历史每页最多100项；带正文历史请求最多10项。创作包导出当前版本与固定依赖，不是全历史数据库备份，最多1000个版本/20 MiB，不包含图片视频二进制或密钥。
- “引用此版本创建剪辑批次”转到智能二创，批次和任务记录固定创作版本。已有视频仍由用户选择、按剪辑参数处理；不会自动按照分镜生成/拼接镜头。
- 模型适配协议预留文本、语音、图像和视频，当前只注册禁用适配器。模型输入计划可以版本化和导出；估价为未知（null），不记为0，无法发起付费调用。AI剧情改写、TTS、图片视频生成及预算预留/扣费对账仍待实现和授权。

P4实机验收：`.\.venv\Scripts\python scripts/p4_smoke.py`；浏览器验收：`node --experimental-websocket scripts/browser-p4.mjs`。会创建明确标识的自编文本与测试视频项目，验证编辑、版本引用和实际剪辑，不使用未授权素材。

本轮升级前数据库备份位于忽略目录 `data/backups/p4-before/database.dump`，已在独立数据库 `story_p4_restore_check` 恢复至0004，并核对原有素材哈希。它不是已复制全部文件的完整备份；当前原始素材原地保留。存在P4版本时，迁移拒绝直接删表降级，应在独立数据库恢复升级前备份，保留当前库与全部文件。

## P5-A/B 文本治理与模拟剧情创作

在“漫剧定制”选中小说、剧本或分集的已保存版本，点击“使用此版本改编剧情”。在“剧情改编”添加离线模拟配置、设置项目模拟额度，填写改编目标，查看最坏费用预留上限后提交。Worker独立执行，关闭页面不丢任务。所有模拟产物标注“非AI生成”，测试费率不代表真实报价。

待审核草稿支持原稿对比、修改正文/分集/对白、历史加载后追加修订和指定版本人工审核。批准后才创建正式剧本及分集大纲，可以引用已审核版本创建真实剪辑批次；回滚沿用“漫剧定制”的追加恢复。未审核草稿无法作为生产版本。

供应商表单仅接受密钥环境变量名称，不输入密钥值。真实配置保存为禁用，不进行联网诊断。价格未知显示null并阻止调用；模拟与真实账户分开。结果未知不自动重发、不释放占用；已保存响应可恢复本地结算。明确失败后的受控重试会新建调用，须确认可能再次收费。账单/退款录入依赖人工凭证，不等于系统已自动核验供应商账单。

本阶段真实请求0、实际支出0；单次真实改编预计费用仍未知，待选定供应商、费率和上限后计算。配置、错误策略和未来授权步骤见 [P5模型契约](docs/P5_MODEL_CONTRACT.md)。未接入图片、视频或TTS模型。

隔离回归使用 `.\.venv\Scripts\python.exe scripts/isolated_regression.py --browser`。脚本创建独立数据库与素材目录，浏览器服务使用备用端口 15179/18006。P5 的数据库恢复脚本对应历史 0006 基线。 [P5 验收](docs/P5_ACCEPTANCE.md)

## P6 本地解析

在素材资产中心进入音视频的“智能解析”，选择需要的步骤并提交。解析记录可查看参数、产物、阶段和日志，切镜或字幕时间可定位至预览播放头。审核快照保存选定解析证据、人工切点和标注，审核稿可以保存为剧本后进入 P5 剧情改编。

模型感知在设置与接口中显示接入状态。当前可使用软字幕抽取、真实波形和人工标注。浏览器复验使用 `.\.venv\Scripts\python.exe scripts/isolated_regression.py --browser-phase p6 --browser-only`，默认把新证据写到 `data/tmp`。 [P6 验收](docs/P6_ACCEPTANCE.md)

进入“生成候选”选择自有或已授权参考图、画幅、帧数和运镜方式。可用本机 CPU 生成候选，再预览并采纳至项目视频素材。供应商 AI 和远程 GPU 仍不可用。 [P8 验收](docs/P8_ACCEPTANCE.md)

## P9 本机配音与字幕

在分镜里固定对白说话者后，进入“配音与字幕”绑定已安装的离线系统音色。验证通过后试听 WAV，导出 SRT/VTT，或把语音和 SRT 采纳为项目素材。 [P9 验收](docs/P9_ACCEPTANCE.md)

## P10 多轨时间轴

在“多轨时间轴”保存画面、叠画、字幕和音轨的片段位置。也可以从已批准制作计划和已采纳镜头自动装配。对已保存版本提交本地渲染，预览实际 MP4 或导出内部工程 JSON。 [P10 验收](docs/P10_ACCEPTANCE.md)

## P11 整剧质检

在“批量生产”选择已批准的制作计划与各集固定时间轴，提交整剧。各集的技术检查随成功渲染自动执行。有硬错误的分集必须返工，已核验的未修改分集可复用。 [P11 验收](docs/P11_ACCEPTANCE.md)

## P12 资源与交付

在“资源与交付”登记作品、分集与素材来源，为目标平台和地域保留人工核权版本。已通过整剧质检且授权有效时可打包实际成片、封面及清单，下载前会再次校验。 [P12 验收](docs/P12_ACCEPTANCE.md)
