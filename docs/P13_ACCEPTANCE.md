# P13 本地剧场、发行登记、推广与结算

基线为 P12 提交 `245e9c5`。本轮的渠道、发行与经营记录基于已通过质检和授权校验的本地交付。平台运营、审核与结算数据由用户依法获取后登记。

## 实现

- 本地登记剧场、机构、账号显示名和地域，追加平台规则版本，记录规则出处和人工核验说明。待核验渠道不会进入人工发行流转。
- 从授权交付包创建手工发行草稿，逐步记录计划、提交、发布、退回或撤回。状态变更按版本和凭证检查，保留时间与依据。推进状态前重新核对授权。
- 从实际成片裁剪高光片段，提取封面并写入标题、简介、原时间段和文件哈希，导出人工审阅推广 ZIP。
- 导入或录入结算，按账号、币种与外部条目号核对重入。现金、广告金、退款、费用、估算和未知分开。按币种汇总已登记现金差额及已知 API 费用，无实际流水时不生成收益。

## 限制与回滚

- 现阶段不包含自动登录、上传、平台挂载、官方接口对账或刷量。规则出处与状态由使用者记录，具体平台准入、发行、资质和备案仍需核实。
- CSV 使用工作台明确的列定义，平台专有报表需依据合计口径整理。当前汇总为已记账现金差额，未测全部人工、版权、税费或电费，不能据此推断整剧利润。
- 已有渠道或推广历史时禁止直接降级。先保留 0012 和相关文件，再在独立数据库恢复 0011 快照配套启用 P12。
