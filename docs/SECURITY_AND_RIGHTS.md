# 安全与版权边界

现阶段为 Windows 本机单人工作台。绑定 127.0.0.1，服务检查客户端地址、Host 和写请求 Origin。上传文件按项目保存，使用内部存储键及解码/封装白名单，处理子进程采用参数数组和超时。本机 API 对同机可信进程开放，账户、角色权限以及对同机恶意进程的防护是后续建设范围。

作品导入记录授权说明。用途、地域、平台、期限、音乐与音色权利证据和发行守门属于 P12/P13。原件、数据库备份、密钥及成片位于被忽略的目录或本机配置。模型输入是非可信数据，当前文本适配使用结构校验，适配器需在本机授权后才能联网。

审计优先项包括媒体工具处理不可信输入、文件和数据库之间的原子性、Windows reparse point、长文本操作消耗、外部地址与凭据绑定、磁盘背压、供应链和完整恢复。当前依赖审核范围见 [LICENSE_REVIEW.md](LICENSE_REVIEW.md)。
