# V3.0 工作台前端改版

基线为 `2a404fe`。此前的专用布局只覆盖智能解析，其他页面多沿用早期表单布局。本轮以素材导入、创作、剪辑、队列和成片交付这条制作链为重点，并给 18 个页面统一工作区标题、导航、状态和移动端布局。

|工作区|实际交付|
|---|---|
|项目总览|项目实拍或本机生成的参考画面、继续制作、导入入口、制作进度和真实记录|
|全局导航|可收起桌面侧栏，页面名称搜索，`Ctrl+K` 聚焦，Enter 跳转，移动端菜单|
|素材库|按类型及名称或授权筛选，独立导入区，视频、图片、音频和 UTF-8 文本预览，流信息和文件哈希|
|小说、剧本、角色、场景、分镜|可按标题筛选当前列表页的创作资产，区分当前和历史版本，编辑区与版本操作分开|
|剪辑与时间轴|批量剪辑可搜索输入并预览首项，设置即时摘要；多轨编辑可监看所选源片段、确认入点和阅读时间标尺，保留拖动、裁剪、吸附及固定版本渲染|
|批量生产与质检|Worker 实时状态、批次与队列并排，按任务状态查询，分页前筛选。成片库只显示已发布的成功渲染，提供预览和下载|
|候选、配音、系统诊断|运镜输入图预览、配音试听区、真实磁盘使用量|

新增的任务视图参数由现有任务 API 处理，旧调用仍默认返回全部任务。筛选和分页不写业务数据，Alembic 保持 `0013`。源片段预览显示选中原素材，最终合成画面以已验证渲染为准。作品授权、发行、模型预算等页面沿用已有业务流程，接入全局界面更新。

## 验证

- 隔离 PostgreSQL 从空库升级到 `0013`，`alembic check` 通过。后端 124 项通过，0 失败，0 跳过，保留一条上游 Starlette/httpx 弃用提示。新增用例用不同项目和状态的任务验证服务端先筛选后分页。 [JUnit](v3-03-backend-tests.xml)
- `vue-tsc` 和 Vite 生产构建通过。12 条 Chrome 生产构建流程全部通过，18 个路由可达，390 像素视口核对素材、创作、时间轴、生产和交付页面宽度。用独立库中的自制样片实际导入、筛选、解析、播放、渲染和交付。 [Chrome 结果](v3-03-browser.json)
- 用浏览器实际导入 UTF-8 文件并从检查器读取，验证导航收起后重载仍保持状态、键盘搜索、队列视图筛选和成片播放器。时间轴的浏览器脚本在首轮因时间标尺改变元素顺序而使用了无效选择器。更新为按轨道角色定位，再复验拖动、裁剪与实际渲染。
- 真实 API 预算 0，真实付费请求 0。UI 示例截图使用独立测试库与自制样片。 [总览](v3-03-overview.png) · [素材](v3-03-assets.png) · [时间轴](v3-03-timeline.png) · [生产](v3-03-production.png) · [成片库](v3-03-quality.png) · [手机](v3-03-mobile.png)
- 本机按生产模式重启后，页面返回新版构建入口，健康检查就绪，1 个 Worker 在线。实际对 7 个现有项目发出只读成片筛选请求。

主要源码在 `frontend/src/layouts`、`styles`、`pages`、`components/production` 和各业务工作台。后端修改为 `backend/app/main.py` 的任务查询，测试更新 `backend/tests/test_overview.py`、`scripts/browser-v3-01.mjs` 与 `scripts/browser-p10.mjs`。

## 复验与回滚

```powershell
Push-Location frontend
npm.cmd run build
Pop-Location
& ./.venv/Scripts/python.exe scripts/isolated_regression.py --v3-browsers --junitxml data/tmp/v3-ui-backend.xml --browser-evidence data/tmp/v3-ui
```

本次数据库没有新迁移。最近一次独立数据库和文件恢复已核验 120 个文件。回滚时等待本机任务结束，运行 `scripts/stop.ps1`，在基线 `2a404fe` 的独立检出重新构建并启动，连接当前的 `0013` 库和存储路径。 [恢复证据](v3-02-recovery.json)
