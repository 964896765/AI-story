## 改动与数据来源

- `frontend/src/App.vue` 是主题和布局壳。`router/` 配置路由、分组和固定版本链接。`layouts/` 提供导航、项目切换和服务状态，`stores/` 持有项目及素材。`pages/` 挂载既有工作区，`components/` 共用任务列表、面板和成片预览。`services/` 与 `types/` 负责新层使用的 API 及类型。
- `styles/` 提供深石墨色、低饱和紫蓝、状态色、边界、间距、字体、响应式导航和原工作区基线。Naive UI 按组件装载主题，Lucide 统一壳和总览图标。锁定 Vue Router 4.6.5、Pinia 3.0.4、Naive UI 2.45.3、Lucide Vue 1.0.0，保留 Vue 3、Vite 和 TypeScript。新增直接依赖的许可证分别为 MIT、MIT、MIT、ISC。
- `backend/app/overview.py` 增加只读 `GET /api/projects/{project_id}/overview`，从原有项目与素材、任务、版本、待审改编、最近整剧批次和费用账本查询。费用按实际入账币种展示，未知供应商账单单独计数。项目参考图取已导入图片，其次可用最近成片画面。六个生产阶段展示已保存的记录数和实际质检结果。
- `StoryStudio.vue` 支持角色和分镜的默认入口，通用创作库保留原浏览器草稿键。`MediaAnalysis.vue`、`TextAdaptation.vue` 与 `ProductionStudio.vue` 适配路由传入的素材、调用或批次。已保存的版本、任务状态、渲染、费用账本和写入接口继续使用 V2 规则。
- `test_overview.py` 验证项目隔离、币种统计、成片筛选及 404。`scripts/browser-v3-01.mjs` 真实上传自制验收画面，使用 Worker 输出 FFmpeg 成片，另使用明确标记的离线模拟得到待审草稿，并验证工作台深链接、项目切换、新建项目、原工作区的媒体探测自动更新。既有 Chrome 回归改用可见导航。

## 数据库与恢复

- `backend/migrations/` 无源码变化。发布沿用 `0013`，无需新增迁移或重建业务库。独立测试库从空库迁移到 `0013` 后执行 `alembic check`。
- 以原库只读转储和关联文件做独立恢复，核对 7 个项目、13 项素材与 120 个文件，恢复 API 素材范围读取返回 206。快照目录记录于恢复结果。 [恢复证据](v3-01-recovery.json)
- 如需回滚，保留当前业务库与素材，停止工作台后用 `60618e0` 配套锁文件重新构建并启动 V2。V3 第一阶段沿用现有 0013 数据结构，正常回滚无需数据库降级。只有数据本身损坏时才在独立目录和数据库恢复备份，验证通过后再切换连接。
