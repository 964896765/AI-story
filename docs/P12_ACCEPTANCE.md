# P12 资源目录、授权和可验证交付

基线为 P11 提交 `63575b1`。以已导入资产为来源登记作品与分集，沿用原件 SHA-256 和固定创作引用。合格的整剧批次支持人工核权后的本地交付。

## 实现

- 将一组项目原始视频按实际集号登记成作品。保留来源、标签、哈希、大小与逻辑归档，支持分页和标题/标签检索。
- 授权按素材追加版本，记录人工核验状态、来源和权利方、商用范围、地域、平台、时间及证据说明。交付解析固定版本、素材与已知衍生链，缺失、过期、未生效、撤回或超范围都会阻断。执行与再次下载时重新核对当前授权。
- Worker 对已通过的实际整剧批次打包，包含各集 MP4 和真实提取封面、已生成的 SRT、固定时间轴、技术及人工质检记录、授权清单及文件哈希。发布前从 ZIP 重读并校验内部文件。
- 保留衍生来源元数据，将最终字幕和成片一同固定保存，供后续交付引用。

## 实测

- PostgreSQL 独立库全量 116 项通过，0 项失败，0 项跳过，保留 1 条上游弃用提示。核验作品检索与归档保留原件、未过质检、授权缺失、已过期、超平台和撤回拦截，以及实际 ZIP 内容和每个文件的 SHA-256。 [后端测试](p12-backend-tests.xml)

## 限制与回滚

- 本地权利记录由使用者提交证据并人工核验。当前覆盖素材和衍生来源，实际发行仍需核对适用许可证、备案、平台规则和 AI 标识要求。资源库保留原件和逻辑映射，二进制物理去重、断点续传及外部资源采集未接入。
- 已有权利、作品或交付记录时禁止直接降级。回滚先保存当前库和文件，在独立库恢复 0010 与匹配文件后用 P11 启动，保留 0011 数据和交付产物。P13 衔接渠道台账、推广和人工状态。
