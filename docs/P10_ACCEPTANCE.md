# P10 多轨时间轴、自动装配与真实合成

本页记录 P10 首次验收。拖动、同轨防重叠、吸附和边缘裁剪见 [直接编辑验收](P10_FRAME_EDIT_ACCEPTANCE.md)。

基线为 P9 提交 `28e5030`。本阶段复用 PostgreSQL、创作版本、Worker、候选媒体及配音字幕，新增可保存和恢复的 24 fps 多轨时间轴。

## 实现

- 主画面、叠画、对白、音乐、音效和 SRT 字幕。支持选择片段、编辑整数帧位置/入点/时长、轨道启用/锁定/音量、轨道顺序、图片运镜和淡入淡出。字幕时间映射到剪辑帧并拒绝输出字幕重叠。
- 自动装配按已批准的故事圣经和固定镜头号引用唯一已采纳候选，缺失、多个候选或时长不足会阻止装配。生成时间轴工作版本后可继续编辑。
- 渲染请求固定具体版本和输入哈希。白名单图形与音频参数进入 FFmpeg，实际混音后限制峰值。成片经过帧数、帧率、音视频规格及完整解码校验，再写文件 SHA-256 并发布。预览使用同一份已验证 MP4。
- 可下载内部工程 JSON 与输入资产哈希。历史恢复追加版本，旧渲染按其原版本保留。

## 实测

- 独立 PostgreSQL 全量 110 项通过，0 项失败，0 项跳过，保留 1 条上游 Starlette/httpx 弃用提示。真实多轨样本含裁剪视频、静图运镜、叠画、两条声音和字幕。三集自编样本使用已采纳镜头自动装配并各自真实渲染，帧数与固定时间轴一致。 [后端测试](p10-backend-tests.xml)
- 前端 Vue/TypeScript 与 Vite 构建通过。Chrome 保存三轨版本并预览实际成片，Range 返回 206。移动字幕、保存 v2，从 v1 恢复为 v3，恢复内容与 v1 一致，无 JS 异常。 [浏览器证据](p10-browser-acceptance.json) · [时间轴截图](p10-multitrack.png)
- 所有素材为本机自行生成的验收样本，外部费用 0 元。三集为短镜头等效样本，商业长剧吞吐留待压力测试。
- 0008 快照在独立库和目录核验 7 个项目、13 项素材和 115 个关联文件，迁移往返及模型检查通过。本机已升级到 0009，API、前端和 Worker 就绪，真实调用仍关闭。 [恢复与迁移](p10-backup-migration-acceptance.json)

## 限制与回滚

- 固定 24 fps，最多 10 分钟、10 轨、50 个片段。叠画采用统一的右上构图，HDR 视频需保留原件并经适用流程处理。现阶段提供数值编辑、轨道布局和最终渲染预览。动态预览、拖拽吸附、关键帧曲线、画面交叉转场、ASS 样式、软字幕轨和 OTIO 待实现。
- 音乐和对白可显式调级并做峰值限制。对白侧链压低音乐与平台响度尚未实测。锁定轨道控制前端操作，权限和跨用户协作待扩展。
- 已有时间轴数据时直接降级会被拒绝。回滚在独立库恢复 0008 快照和对应素材，配套启动 P9 代码。保留现库、版本与产物。P11 将在本地渲染基础上加入整剧任务与质检返工。
