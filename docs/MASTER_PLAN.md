## 1. 产品定位与核心指标

本地优先、云算力可插拔的工业化漫剧/短剧制片系统；面向个人制片、后续小团队及商业化部署。统一项目/剧集/镜头/版本/资产/任务/费用/交付的业务模型，支持按部、按集、按场、按镜头复用和重制。核心竞争力不是单次出片，而是有效成片成本、人工分钟数、首轮通过率、稳定性、复用率和端到端效率。

定义六种生产模式：素材加工（纯本地视频处理）、静态漫剧（图+运镜）、授权二创（合法复用及改编）、混合动态（静态+动态）、全动态原创、授权多语言本地化。模式由模板和能力策略表达，不复制业务模块。每个项目允许混合模式；镜头支持不同生成方式及供应商。初期商业验证目标以一部自有原创短剧 3 集为主，逐步放大至 20 集/60 集，禁止在未验证实际单集成本前自动扩量。

指标必须定义口径：真实端到端耗时、付费生成秒数、实际可用成片秒数、单集实际发生费用、费用未知项、返工倍率、人工审核次数和时长、成功/失败/取消/跳过任务数、模型限流/超时率、资产命中率、质检通过率。展示测试数据与真实生产数据的区别。不要承诺未实测的效率、原创认定、平台收益或审核通过率。

## 4. 多媒体解析引擎（原始视频变成可检索的结构化信息）

### 4.1 本地确定性处理
- ffprobe 提取容器、时长、码流、时间基、SAR/DAR、旋转、色彩信息、HDR、分辨率、帧率、VFR/CFR、音轨/字幕轨及语言。正确处理无音轨、多音轨、损坏文件、异常 PTS、流与容器不一致。
- 解封装与分轨：视频、每个音频流、软字幕等独立提取；保留流映射及时间偏移；混合音轨不能假称已分出人声/音乐/音效；硬字幕只能识别，不是可直接提取的字幕流。
- 转封装（stream copy）与重新编码分开；使用真实兼容性检查。保留原始素材，低分辨率代理仅用于预览/分析；最终合成优先原素材。支持分辨率、画幅、帧率、像素格式、码率或 CRF、音频编码、采样率与声道、响度目标；HDR 必须显式处理，不擅自破坏色彩。
- 抽帧：按时间、场景、关键帧/采样策略，记录 PTS、源镜头和缩略图；不要每帧上传云端。镜头检测用现有 FFmpeg 或按需接入 PySceneDetect/OpenCV，输出切点、分数和算法版本，支持人工合并/拆分，不能把视觉切镜直接当剧情分场。提供镜头联系表、波形及缩略图缓存。
- 视频片段的逻辑入出点和物理文件分离，优先非破坏性引用，减少复制；需要帧级精确时选择适当重编码而非无条件 stream copy。

### 4.2 AI 感知
- ASR：可插拔 Whisper/FunASR 或经授权云端服务；输出句/词级时间戳（能力允许时）、语言、置信度、修订历史；支持分块重叠、长音频对齐及去重。
- OCR：可插拔 PaddleOCR 等；识别画面文字、硬字幕位置和持续时间，合并重复帧并与 ASR 对齐；冲突待人工确认。
- 音源分离：Demucs/MDX 等候选方案仅在安装、许可、资源条件满足时启用；输出估计的 stem、质量提示，分离残留可听检；不得宣称从混合音频完美恢复独立原始轨。
- 说话人分离、VAD、人物候选聚类：输出带时段的候选标签及人工映射，不将声纹推断或聚类当成真实身份。声音克隆/身份相关能力只处理有授权用途。
- 多模态视频理解：按镜头关键帧/短片+转录文本+上下文分层分析场景、动作、情绪、景别、角色候选、道具、对白和事件；先局部后跨集汇总；输出 JSON Schema、证据指针和置信度，模型结果不可直接覆盖源事实；只发送必要且已授权的素材。
- 解析缓存键包含文件哈希、算法/模型及配置版本。单步骤失败可恢复；解析结果分阶段落库；支持人工修订并形成可供创作引用的快照。

## 5. AI 创作、剧情改编与跨集连续性

- 原创小说/剧本导入、章节索引、长文本切块、逐级摘要及可追溯来源；允许授权参考视频的结构化解析入库。故事圣经保存世界观、时间线、规则、主题、角色目标、关系变化、伏笔及回收、每集摘要和跨集连续性状态。
- 工作流：创意/题材 → 故事纲要 → 分集策划 → 场次 → 剧本/对白 → 分镜 → 生产规划。每层结构化输出，保留输入版本、模型、提示词、参数、证据、候选与审核状态。允许批量生成、逐集审核、对比及局部再编。未确认的草稿不得直接进入付费生产。
- 分镜须包含稳定镜头 ID、场次、预计时长、景别、角度、运镜、光线、构图、人物/服装/场景/道具固定版本、人物动作、对白和说话者、情绪、音效、转场、生成策略及审核项。区分计划时长和实际成片时长。校验总时长、引用完整性、对话与动作时间是否可行。
- 一致性：定妆参考、多角度/表情/服装约束、角色色表、场景布局与光线、镜头前后状态、道具连续性、视线/轴线提示；沿用同一固定参考版本，使用供应商真实支持的参考图、seed、首尾帧或工作流节点，不能保证绝对一致。角色相似度与连续性算法只做辅助，不代替审核。
- 提示词系统：全局风格+角色/场景+镜头模板+模型适配，版本化、变量校验、长度限制、输出 schema 校验；对模型输出视为非可信数据，禁止将素材文本中的指令直接执行为系统命令。改编评估重视叙事合理性、授权范围与原创表达，不提供绕过检测的目标或承诺。

## 6. AI 生成与多模型能力中心

采用现有 `model_adapters.py` 契约演进，接口按能力划分：文本/视觉理解、图像生成/编辑、视频生成、语音、可选音效和口型。同步与异步接口均可支持，明确供应商功能矩阵、支持格式/时长/分辨率/参考数量/语言/商用条件；未实现功能不可展示为可用。

- 文本优先选择价格可控的兼容接口；图像/视频/语音候选可包括 DeepSeek、通义千问/Qwen-VL、Seedream、FLUX、Seedance、海螺、万相、可灵、Vidu、CosyVoice、ComfyUI 等。仅为候选，不预设所有型号可用。实际接入时检查官方文档、地域、接口权限、当期价格、数据政策及许可证。禁止写死会过期的价格/模型名或将第三方渠道报价当成官方报价。
- 角色定妆图、场景图、道具图、分镜首帧、候选图；图生视频、文生视频、参考生视频、首尾帧仅对供应商支持的能力启用。候选生成可限数量，输出自动下载、校验、隔离临时文件，人工或守门规则选用；镜头不通过时只重制该镜头及相关产物。
- 人物对白：角色-音色版本绑定；语速、情绪、停顿与读音词典（供应商支持时），分句合成，字/句时间戳、配音试听、多候选、音画同步；多语言保留原文/译文/修订稿。语音克隆必须有本人或权利方授权。
- 混合算力：简单画面用静图运镜，中等动作走低成本图生视频，关键动作走高质量模型，用户可覆盖。普通剪辑/渲染优先本地，昂贵生成先样片比较再放量；策略由能力、可用性、预算、实际首轮通过率和质量偏好共同决定。不自动降级质量或擅自发送至其他外部供应商，回退须符合授权和预算。
- 本机优先 CPU/轻量 FFmpeg，硬件编解码仅经实际检测后可启用；现有 MX450 2GB 不作为大模型运行的前提。可选远程 ComfyUI/GPU 工作节点与对象存储，资源配置独立、默认关闭，云实例计时与关闭需明确授权和状态核实。

## 7. 多轨时间轴与后期制作引擎

目标是自动化制片时间轴，不重造完整剪映。先实现可靠可序列化的时间轴模型及渲染器，再实现编辑交互。

轨道：主视频/图片、辅助视频叠加、字幕/文字、人物对白或旁白（可多轨）、背景音乐、环境/动作音效、可选特效/转场；每轨有顺序、启用/静音、音量/混音配置和锁定，画面合成顺序明确。

- 以整数时间基记录 timeline start、source in/out、持续时间、速度与素材引用；镜头剪切、移动、拆分、重排、替换、吸附、画幅设置、缩放/位置、静图 Ken Burns 运镜、可控转场、淡入淡出，关键帧先支持核心变换。字幕 SRT/ASS/VTT 导入导出、样式模板、中文字体及授权、时间戳校验；支持硬烧录与适用的软字幕，明确区别。目标输出可选 MP4/H.264/AAC 等通用预设，平台要求由版本化 profile 管理。
- 音频：采样率与声道统一、音量/响度、对白优先压低音乐（ducking）、淡入淡出、峰值/削波保护、无音轨处理、对齐、音乐授权、音效定位。音轨不足以达到目标时显式提示；不得随意拉伸对白或截断内容掩盖错误。
- 非破坏性编辑：版本化时间轴、撤销/重做、快照、自动保存与冲突处理；生成结果一键落轨；基于固定镜头时长生成初始时间轴。支持镜头级复用及替换，重新评估字幕/音频和拼接依赖。
- 预览使用代理视频、缩略图/波形缓存与时间范围加载；大项目虚拟列表，不一次加载数千个原视频。代理预览与最终输出规格严格分离。
- 渲染计划先校验后执行，FFmpeg 采用 argv，不拼接未经校验的 Shell 或滤镜表达式；仅允许白名单滤镜与参数，单独处理字幕路径转义、中文路径、旋转和 VFR。分段渲染、缓存键及合成检查点；临时输出、ffprobe/实际解码校验成功后原子提交，输出 SHA-256、参数和时间轴版本。不能仅依据 FFmpeg 退出码判断交付成功。
- 先支持内部工程 JSON + 素材清单、SRT/ASS/VTT 和通用成片，后续按实际兼容验证实现 OTIO 或其他开放编辑交换格式；不要承诺剪映专有草稿兼容或绕过平台接口，未验证标明实验性。

## 8. 工业化任务系统与存储

优先复用持久化 Worker 和 PostgreSQL。初期不强制 Redis/Celery/Kubernetes；实测吞吐不足再引入适配层，避免同时存在两套任务真相。

- 工作流 DAG：可保存版本、参数、依赖、步骤输入/输出契约，禁止循环依赖。按项目→批次→剧集→镜头→步骤拆任务；支持本地与外部异步任务。提供不同资源类型池（CPU/编码/云模型/下载等）、并发限制、优先级、公平调度和磁盘背压。
- 任务状态明确区分 queued、running、waiting_external、retry_wait、needs_review、blocked_budget、blocked_config、cancel_requested、cancelled、failed、succeeded、unknown 等；落实允许迁移表、真实进度、可追踪错误。进度不明就显示不确定，不能用定时器伪造。批次成功仅在其必需步骤和交付验证完成后成立。
- 原子任务领取、租约/心跳、超时回收、锁/期望版本、崩溃恢复、检查点、有限重试与指数退避/抖动、失败分类、人工介入。PostgreSQL 可考虑事务+SKIP LOCKED，具体遵循现有实现及并发测试。
- 幂等键覆盖业务请求与供应商调用；内部与外部操作分开记录。外部 API 若不支持幂等，超时或断网后先查询远程状态/对账，不盲目再次创建付费任务；明确无法保证外部 exactly-once 的边界。取消不等于供应商退款或立即停止计费，保留真实状态。
- 缓存与增量失效：内容/配置/版本哈希决定可复用性；修改角色不改变已有固定版本，只让显式采用新版本的依赖进入重算计划。改一镜头只重跑失效依赖及必须重合成的集，复用未变化文件。失败产物隔离，生命周期清理不删除活跃任务/固定引用资产。
- 存储：本地抽象 Storage backend（校验路径、原子写、分块上传、Range、配额）；后续扩展 S3 兼容，不作为初期必需。大文件上传、重启恢复、断点能力按实测交付；文件名不能直接充当路径。备份包括一致数据库快照及匹配文件清单/哈希，实际恢复至独立库和目录验证；只有 DB 备份不得冒称全量备份。

## 9. 费用、预算、供应商与算力治理（付费调用硬门槛）

- 默认真实调用关闭且预算 0 元。供应商配置只保存密钥引用，密钥使用环境变量/OS 凭据库或经审计的安全配置。区分连接测试（可能收费/上传）、模拟、真实；明确每次外部调用的授权范围。不得输出密钥至浏览器、日志、Git、导出包。
- 能力目录记录服务商、模型 ID、规格、计费单位（Token/张/秒/字符/积分/GPU 时长）、价格来源、更新时间、生效时间、币种、税费与可确定上限、输入/输出/参考素材附加费、是否收费失败、最低计费长度及不确定性。价格未知/过期且无法预估上限时阻断付费调用。
- 多层预算：全局/项目/批次/剧集/模型或日度阈值；先生成生产计划及上限报价，再事务中检查所有适用预算并预留，防多 Worker 并发越限。预留与结算分开；失败确无计费才释放，状态未知继续占用，直到查询或人工对账。额度不足自动阻断新请求，不自动偷偷切换收费模型；已在途费用不能因取消而抹掉。
- 记录不可混淆的 estimate/reserved/actual/unknown/released/refund 字段或独立账本事件；供应商重试和退款、账单导入、差额对账及重复结算保护。保留历史价格快照，不能用现价重算旧账冒充实付；缺实际费用时显示未知，不显示 0。
- 成本路由与 benchmark：同一组合法镜头样例、同规格、同参考版本比较各模型实际生成耗时、排队时间、可用片段长度、人工评分、重试次数、实际相关成本，计算有效成片每秒成本而非仅供应商标价。任何 A/B 真实调用也走预算。保留人工选择与降级建议，不自动无限重试。
- 模型费用之外记录本地资源估算、云 GPU 按时收费、存储/出网、外包/版权/人工等（手动导入或估算明确标记）。单剧预测成本与实际成本并排；收益未知不虚构利润。

## 10. 质量检测与审核闭环

分层 QA：技术硬门槛（可确定检测）、模型辅助评分（可能误判）、人工审片（审美、剧情、合规）。每项 issue 有级别、阈值/规则版本、真实证据、素材/镜头位置、建议、负责人、修复状态及复检结果。

- 技术检查：文件存在/哈希/解码、流、时长/分辨率/帧率、PTS/DTS、空白/黑帧、冻结、异常跳变、静音、削波、响度、字幕重叠/越界/缺失、剧集完整性。按项目策略设阈值；黑场/静音可能是艺术设计，支持记录合理豁免，不无条件删除。
- 内容检查：角色/服装/场景/道具连续性、关键对白、叙事连贯、音画同步、文字可读性、视觉变形及生成缺陷，模型辅助输出不当作客观真相。跨集首尾连贯及人物状态需要人工评审。
- 审核节点：脚本、角色与场景参考、生产预算、样片、最终成片/权利与交付。批量审核允许但须明确对象、版本和结果；发布级硬门槛不能静默跳过。
- 返工：直接从 issue 跳转到镜头/时间轴；只生成必要步骤，保留旧成片与差异对比；重新质检相关范围和完整集；生成人工任务处理无法自动修复的问题，不做无限循环。

## 11. 交付、发行、推广与经营

- 交付包：按剧/集输出成片、封面、标题/简介、SRT/ASS 等字幕、可选配音及音轨、镜头和角色资产清单、授权/AI 标识/备案材料清单、真实创作过程及版本变更日志、manifest（文件列表、SHA-256、规格、固定版本、质检状态）。真实过程图可根据系统真实记录生成，不伪造工程图、制作记录或原创证明。
- 文件夹命名稳定、按剧/集序号排序、可恢复导出，不覆盖其他作品；导出前检测磁盘和权利/审核状态。素材工程交换与完整恢复分开，不默认打包所有历史和敏感文件。
- 视频号蓝V剧场及其他平台：管理用户实际登记的机构、剧场、账号、授权关系、作品、剧集、发布计划、人工上传状态、备案/许可材料和期限；官方规则配置记录来源、日期、状态，待核验须显式标记。平台准入、广电许可、AI 标识与结算条件由用户向主管部门/平台核实，不因软件能导出而视为满足。
- 推广素材：从自有/授权剧集挑选合理预告、剧情导读和高光片段，生成封面标题字幕、关联授权作品；预览和人工审核。使用官方允许的账号授权与发布方式，初期采用发行素材包+人工上传+官方报表导入；没有可靠官方 API 的自动发布、挂载、结算功能保持禁用，不存平台密码或模拟登录绕限制。
- 经营账本：导入/手动记录实际结算单、平台/剧集、期间、收款状态、税费/合作分账及来源。区分广告金与现金、毛收入与实收、估算与确认、播放/有效广告观看等口径；按剧/集/平台/模型汇总费用、利润和回本点。核对重复账单和退款，保留对账证据。不得虚构自然流量、收益或完成平台审核。

## 12. UX、API、安全、运维

- UI：延续专业、极简、高级影视工作台，弱装饰、统一设计 tokens；左侧可收起主导航、项目面包屑、中央工作区、右侧上下文参数/审核面板、必要时底部时间轴。选择项目后统一资产/任务/版本上下文，深链接回具体镜头并保留编辑状态。首页真实数据不堆无效卡片。中文长文本、路径、空/加载/错误/禁用状态、键盘可达、焦点管理、响应式（手机至少可看任务与审核，复杂剪辑以桌面为主）。
- API：保留现有客户端兼容性，增加版本化 schema/OpenAPI 文档、分页、过滤、结构化错误、请求 ID、幂等键、乐观锁冲突和权限边界。长任务异步返回 ID，使用 SSE/WebSocket 或可靠轮询展示真实事件；断线重新读取权威状态，不丢任务或重复提交。
- 安全：本机服务也需限制 Host/Origin/CORS、对有状态请求考虑 CSRF/本机令牌、路径遍历/符号链接/Windows reparse point、文件类型/容量/内容检查、解压炸弹、下载 SSRF 与外部 URL 白名单、子进程参数与超时、凭据和日志脱敏。导入的小说/字幕/图片/模型输出均为不可信数据；不执行模型给出的代码或 Shell。依赖锁定、供应链及许可证扫描，新增依赖前评估商用与安全；漏洞报告分清已知与未扫描范围。
- 文件、授权、API 密钥、数据库备份和生产成片不得提交 Git；必要测试素材采用自行生成或明确许可。默认不外发数据，外部供应商的素材保存/训练政策与保密条件可见；上传前遵循用户授权。可选多用户角色/租户、审计、密钥及公网硬化将来单独评估，当前不开放公网。
- 启动/运维：统一 Windows PowerShell 启停/诊断脚本，Docker PostgreSQL 持久卷，后端/前端/Worker 独立生命周期；端口冲突、FFmpeg 不存在、数据库不可达、磁盘不足等明确报错；停止服务时核验进程身份，不杀死其他项目服务。日志轮转、资源监控、数据库及文件备份恢复脚本、版本号和迁移策略。无意外收费的离线测试默认可运行。

### 总体验收矩阵（必须落到测试代码与证据）

1. 回归：现有 P0–P4 后端测试及后续已有测试全部跑；失败不得删除断言或降低覆盖以求绿灯。前端类型检查、生产构建、依赖检查、真实浏览器主路径和键盘操作。
2. 媒体：合成/自有样本有多音轨、软/硬字幕、旋转、VFR、无音轨、损坏、不同编码；分别验证导入、分轨、字幕、时序、转码、剪辑、可播放成片及原始文件哈希。
3. 并发与故障：同时提交、重复提交、跨项目引用、版本冲突、Worker 被中断/重启、FFmpeg 失败/超时、外部 429/5xx、未知结果、磁盘满、文件损坏、部分失败、取消与清理；队列恢复无重复输出/可避免的额外付费，未知付费状态保留并对账。
4. 预算：模拟平台覆盖每个状态和并发；真实供应商测试必须有明示的单次预算和可确定收费上限，使用最短合法样片，保留真实账单/任务 ID（脱敏）。任何模型实际不可用时在能力矩阵标注，禁止将 mock 通过等同真实模型质量。
5. 生产：先使用自编 3 集（每集可 30–60 秒）完成文本/分镜→素材→多轨时间轴→真实成片→质检→交付；没有真实生成授权时使用明确标记的本地合成/人工样本验证流水线，不宣称原创 AI 生成已验收。之后 20 集本地/模拟压测，按实际内存/磁盘测并发、恢复和局部返工；真实 20/60 集商业生产必须在样片验证及预算批准后执行。
6. 质量：制造缺失音轨、黑帧、重叠字幕、错误分辨率、缺镜头等可识别问题；验证 issue 定位、返工、复检和不可跳过的发布门槛。视觉/剧情评分由人工或已验证模型辅助，报告主观限制。
7. 数据：升级前备份；独立库验证迁移与恢复；有历史时拒绝破坏性降级；完整数据库与文件快照恢复、核对引用及哈希；版本回退不删除后续业务数据。所有回滚步骤可复现。
8. 安全：路径穿越、恶意文件名/解压、SSRF、未授权项目访问、非法状态转换、密钥脱敏、命令注入、非法/过期授权导出阻断。许可证审计覆盖新增依赖及模型权重使用条款。
9. 经营：账单重复导入不重复累计，预估/未知/已结算区别明确；人工发布记录不冒充成功发布；不依赖付费推广或多号资源验证本地生产功能。

## 15. Codex 现在开始执行的动作

第一轮：在指定路径执行审计。核对最新 Git/文件/运行状态/迁移、已有 P5 实现以及现有测试。将本总纲保存至工程 docs/MASTER_PLAN.md，建立能力矩阵、更新分阶段任务及架构契约。不要回到已完成 P4 重写全部功能。

第二轮：完成当前最早未验收的硬依赖（优先 P5-A 模型治理、费用与预算）。按实际现状拆成小提交，同时允许推进不依赖付费模型的 P6-A 本地解析、时间轴契约等基础工作。完成到可实际运行的纵向闭环，不停留在只写文档或 UI 的阶段。

后续：按阶段增量推进，单阶段完成真实测试后更新矩阵。若模型调用未授权，真实接口保持关闭，完成所有可离线验证的功能，并明确下一次真实验收所需的供应商、配置、价格来源、预算和输入样本。不要以缺少 API Key 为由停止所有开发。不得在没有授权的情况下用真实收费请求替代模拟。

最终交付标准：用户能在本机创建作品、导入原创或授权素材、选择生产模式、审核剧情与角色、执行批量任务、定位失败镜头并返工、通过多轨时间轴真实输出并质检多集成片、导出合法发行素材包、查看真实成本并登记实际收益。付费 AI 能力和真实商业发行只在相应授权与实测完成后标为可用。整个系统以可运行、可复现、可恢复、可追踪、可控成本为第一原则。
