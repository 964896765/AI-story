## 本机发布范围

本机已验收能从固定分集分镜和实际媒体生成多轨成片，按集质检、返工、核验授权、打包交付及记录人工发行。真实文本供应商、生成式图片和视频、远程 GPU 及外部账单的联调仍需获得配置、条款与授权。多人语音转写基准、说话人分段、视觉理解、音源分离、时间轴高级编辑、镜头级增量生产，以及媒体资源去重和断点上传仍有独立开发工作。实际平台的账号接入、发行和经营数据有单独的凭证及授权要求。
