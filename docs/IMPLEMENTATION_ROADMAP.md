# V2.0 实施路线

保留既有 P0–P4 工程和 Git 历史。验收样本使用自编文本和自行生成的媒体。先走通 3 集本地生产，随后进行 20 集压力测试。真实供应商调用等待明确授权和逐次验收。

|阶段|实施顺序|验收与回滚边界|
|---|---|---|
|P0–P4|审计代码、入口、迁移和历史证据；回归统测|独立库回归、前端构建和浏览器；复用 P4 固定版本及原始文件|
|P5-A|目录与配置快照、报价/预留、队列、未知状态、对账/退款|重复请求和并发余额测试；真实预算默认 0；保留收费审计记录|
|P5-B|固定稿件、结构化结果、编辑与拒绝/采纳、正式生产版本引用|模拟和真实结果分开；付费实测需独立授权、供应商条款、限额与账单证据|
|P6-A|流清单、分轨、代理、抽帧、切镜、确定性转码|多音轨/字幕/旋转/VFR/损坏样本，验证原件哈希、产物和源时间基|
|P6-B|感知适配、对齐、证据快照和人工修订|本地可复现测试，模型安装或网络调用独立授权|
|P7|故事圣经、跨集状态、角色/道具/场景约束、可审核的结构化分镜|至少 3 集；固定引用、连续性问题定位；真实生成另测|
|P8|图片视频候选、算力策略、供应商状态、结果安全下载、候选采纳|有限预算、超时未知保留、局部重制与缓存；真实样片经授权|
|P9|音色版本、分句配音、字幕时序、分离及音效|多角色、对齐、授权与混音，区分合成测试音频和真实 TTS|
|P10|整数时间基、可版本化多轨、自动落轨、预览/渲染|3 集或等效审片样例，验证移动、裁切、运镜、字幕/多音轨和版本恢复|
|P11|整剧 DAG、质检、局部增量重跑、整剧报告|3 集成片和 20 集压力测试；重启、取消、磁盘不足、失败隔离|
|P12|作品/剧集资源、权利核验、交付与工程清单|授权过期/范围拦截；实际输出及制作证据与清单哈希核对|
|P13|剧场、发行计划、推广素材包、报表/结算和经营指标|人工-平台状态区分；现金/广告金、重复结算防护；仅使用授权渠道|
|P14|性能与安全、完整恢复、跨平台准备和发布|吞吐、复用、实际费用、键盘操作、数据库和文件完整恢复、发布检查|

每个阶段先在独立数据库验证迁移和恢复。遇到不可逆历史表或已产生资产时，在独立库恢复升级前的数据库与文件快照后再选择切换。阶段验收记录与 Git 提交分别保留。
